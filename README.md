# Ronin

**Native intelligence for Linux.**

Ronin is a native Linux AI workbench: threaded AI chat, explicit context tools, local memory/artifacts, and hybrid local/cloud model support. It is planned as a Rust + GPUI desktop app with a fast CLI launcher and local-first data storage.

## Packaging (Linux)

Install the binary, `.desktop` entry, and icons with `make install` (or `./scripts/install.sh`). See [docs/packaging.md](docs/packaging.md) for install/uninstall paths and binding `ronin --quick` on GNOME, KDE, and Sway.
