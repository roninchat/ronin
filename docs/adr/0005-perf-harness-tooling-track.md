# Perf Harness is a tooling track, not a product wedge

The Perf Harness lives in this repo (alongside Ronin crates) so it can share Paint Timing seams, but it is developer tooling — not the next user-facing milestone and not a reopen of trust-before-agency / no-automation product non-goals. Shipping `ronin` stays free of the harness control plane (see ADR-0001).
